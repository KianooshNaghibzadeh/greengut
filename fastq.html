GreenGut qPCR Gut Health Report

Upload the Ct values your lab returns for 20 bacterial targets/groups. GreenGut converts each one into an estimated load relative to the universal 16S assay, places it among – healthy reference chickens aged 0 to 21 days, and builds a three-page report for you or your vet. Food-safety pathogens are reported separately from the balance score.

From Ct to load relative to 16S

A curve that crosses the threshold one cycle earlier means about twice as much of that target. The 20 loads are not forced to add up to 100%.

The healthy reference

How often each target turns up in healthy reference chickens and its usual load when quantified. Pick a target to see every reference value. Only quantified values are used; ND, <LOD and <LOQ are never treated as zero.

What to send

One CSV, one row per sample, saved from Excel. Start from the blank form so the column names match. The file is checked before processing; any problem is listed with its row number and column name. The example values below come from our example file.

ColumnExampleWhat goes in it
Sample_IDYour own label for the sample
Age_DaysRequired. Exact age in days; used for the age-match confidence. The reference covers 0 to 21 days.
Total_Bacteria_Ct_1, _2Universal 16S (total bacteria) assay in duplicate. Every target is expressed as a load relative to it.
Lactobacillus_Ct_1, _2One duplicate pair for each of the 20 targets. Replicates more than 0.5 Ct apart are flagged and excluded from the score.
Lactobacillus_Efficiency_pctRequired for every quantified target. 90 to 110 is expected; an empty value is never assumed to be 100.
Salmonella_Ct_1Write ND, <LOD or <LOQ exactly as the lab reports it. These are never counted as zero.
Negative_Control_Ct, Extraction_Control_CtAmplification before cycle 35 in either blank fails QC and stops the score.
Positive_Control_Ct, Inhibition_Control_Shift_CtThe positive control must amplify; an inhibition (spike-in) shift above 1 Ct fails QC. Each control is checked separately.
Probiotic, Antibiotic, FCROptional flock details. They are printed on the card beside the result.

What comes back

A three-page report for each sample, saved as a PDF that records the platform, algorithm, baseline and assay panel versions. Your file is read in your browser and is not uploaded anywhere.

Page 1

Score and verdict

Microbiome Balance Score (0 to 100), its place among healthy chickens, dysbiosis risk, age-match confidence, and a separate food-safety pathogen panel. No score is given if lab QC fails.

Page 2

Every target

Each load drawn against the P10–P90 reference range, with its percentile, the reference counts (quantified, detected, total) and a status.

Page 3

Flags and lab checks

What each flagged target usually points to, target panel coverage, standardized panel distance, every control checked separately, and the reference details.

Want to see one first? The example file holds four samples, including one that fails lab QC and therefore gets no score.

Report

Prototype research reference. The healthy reference comes from published scientific datasets () and has not yet been calibrated against qPCR. It will be replaced by a real qPCR baseline from field samples; a commercial version will follow only after validation against FCR, weight, mortality and clinical status. The report describes a sample; it does not diagnose disease or replace your veterinarian.
